# Testing Procedure

# GoldTester
## Version 1.0

---

# Objective

Verify that all hardware and software modules work correctly before operating the machine.

---

# Test Checklist

## Display Test

- Display powers ON
- No flickering
- Text displays correctly
- Screen refresh is smooth

Status: ☐ Pass ☐ Fail

---

## HX711 Test

- HX711 detected
- Stable raw values
- Force reading updates correctly

Status: ☐ Pass ☐ Fail

---

## Motor Test

- Forward rotation
- Reverse rotation
- Smooth acceleration
- Smooth stopping

Status: ☐ Pass ☐ Fail

---

## Load Cell Test

- Zero calibration successful
- Known weight measured correctly
- Stable readings

Status: ☐ Pass ☐ Fail

---

## Force Control Test

- Target force reached
- Motor stops at target
- No overshoot

Status: ☐ Pass ☐ Fail

---

## Safety Test

- Emergency stop works
- Maximum force protection
- Motor disables on fault

Status: ☐ Pass ☐ Fail

---

## System Test

- Boot successful
- No crashes
- Continuous operation
- Serial logs normal

Status: ☐ Pass ☐ Fail
